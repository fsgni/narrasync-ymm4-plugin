NarraSync2 YMM4 プラグイン

ゆっくりMovieMaker4 に AI 素材生成を組み込むツールプラグイン

最新版をダウンロード

zip を展開して user\plugin\ に置くだけ

台本（YMM4 のセリフ）を読み取って、各行に合った挿絵を AI が生成し、タイムラインに自動で並べます。 立ち絵の表情や補足テロップの自動配置もできます。

音声合成・字幕・口パク・エンコードなど YMM4 が既に持っている機能はそのまま。 AI が必要な部分だけを足す作りなので、いつもの編集の流れを変えずに使えます。

  • 導入
  • 最初の設定
  • 基本の流れ（素材生成）
  • 部分的なやり直し
  • 素材の配置枠（全画面を使わない場合）
  • 画像エフェクト
  • 立ち絵の表情を自動設定
  • 補足テロップの自動配置
  • 困ったとき

導入

  1. ダウンロード 上の「最新版をダウンロード」から zip を取得します。
  2. YMM4 を終了する 起動したままだとファイルが使用中で置き換えられません。
  3. zip を展開して配置 中に入っている NarraSync2 フォルダを、フォルダごと YukkuriMovieMaker_v4\user\plugin\ に置きます。 
    YukkuriMovieMaker_v4\
  user\
    plugin\
      NarraSync2\
        NarraSync2.Ymm4Plugin.dll
        NarraSync2.Ymm4Plugin.deps.json
    すでに古い版がある場合は、この 2 つのファイルを上書きしてください。
  4. YMM4 の自動更新を切る このプラグインは YMM4 4.53 の内部構造を直接利用しています。 YMM4 が更新されると動かなくなる可能性があるため、自動更新はオフにしておいてください。
  5. YMM4 を起動 メニューの「ツール」から NarraSync2 取り込み を開きます。

動作確認環境：ゆっくりMovieMaker4 v4.53 / Windows

他のバージョンでは動かない場合があります（内部構造が変わるため）。

最初の設定

接続設定

パネル上部の「接続設定（URL・ログイン）」を開き、管理者から教わったバックエンド URL・ユーザー名・パスワードを入力します。 一度入力すれば保存され、次回からは畳まれた状態で開きます。

レイヤーの指定

「レイヤーを自動検出」ボタンを押すだけで、たいていは正しく埋まります。

項目意味
素材レイヤー生成した挿絵・実写素材を置くレイヤー
セリフを読むレイヤー台本として読み取るレイヤー（空 = 全レイヤー、カンマ区切りで複数可）

番号でもレイヤー名でも指定できます。自動検出を押すと、各レイヤーの中身（セリフ〇件・立ち絵〇件…）付きの候補が ドロップダウンに並ぶので、そこから選ぶこともできます。

基本の流れ（素材生成）

YMM4 でいつも通りセリフを並べて保存（Ctrl+S）したら、 オプションを選んで 「素材生成」 を押すだけです。 台本の分析 → 各行の絵の内容決め → 画像生成 → タイムラインへの配置まで自動で進みます。

既存のアイテムは書き換えません。 生成した素材は指定レイヤーに追加されるだけで、あなたが作った立ち絵・字幕・装飾はそのまま残ります。 実行前に プロジェクト名.ymmp.bak のバックアップも自動で作られます。

主なオプション

動画化する

生成した静止画をさらに AI で動かして動画にします。時間はかかりますが動きのある画になります。

既にある部分はスキップ（空白のみ生成）

すでに素材が置いてある行は触らず、まだ何も無い行だけ生成します。追加・修正のときに使います。

実写素材の割合・種類

指定した割合の行を、AI 画像の代わりに実写のストック素材（Pexels / Pixabay）にします。 風景・物の説明などナレーション寄りの行が対象で、キャラクターが登場する行は AI 画像のままです。 0% で無効。

すぐ下の「実写素材の種類」で 動画 / 写真 / 動画＋写真 を選べます。

  • 動画：従来どおり。行より短い素材は自動でループします
  • 写真：静止画。尺の制約が無いぶん素材が見つかりやすい （動画だと「行より短いクリップしか無い」ことがあります）
  • 動画＋写真：行ごとに動画と写真を交互に割り当てます。 その行に片方が見つからなかった場合だけ、もう一方から選びます
以前の版では「動画＋写真」にしても、実際にはほぼ動画しか選ばれませんでした。 ストック動画はほぼ全て正確に 16:9 なのに対し、写真は 3:2 や 4:3 が多く、 画面比の一致度で写真が必ず負けていたためです。交互割り当てに変更して解消しました。

スタイル参照画像

1 枚の画像を指定すると、全ショットの画風をその絵柄に寄せます。

角色参照

登場人物の見た目を固定します。「話者から追加」で台本に出てくる話者を一括で並べ、 それぞれに参照画像を指定してください。その人が登場する行にだけ参照画像が使われます。

本文に出てくるだけの人物（喋らない登場人物）は「行を追加」で名前を手入力できます。

部分的なやり直し

タイムラインでアイテムを選んでからボタンを押すと、その部分だけ作り直せます。

ボタン選ぶものすること
画面再生成画像その画像を作り直す（スタイル・角色の参照画像も反映されます）
画像to動画画像その画像を動画に変換して差し替える
動画再生成動画元の画像から動画を作り直す
未生成補完セリフまだ絵が無い行にだけ生成（台本の再分析はしません）

「動画再生成」はこのプラグインが作った動画だけが対象です。 あなたが自分で入れた動画素材は、選んでも絶対に触りません。

素材の配置枠（全画面を使わない場合）

「挿絵は右上だけ、下は立ち絵と字幕」のように画面の一部だけを素材に使う チャンネル向けの設定です。枠を決めておくと、生成される素材（AI 画像も実写素材も）が その枠に収まります。

おすすめ：YMM4 の画面で決める

一番正確で速いのはこの方法です。見当をつける必要がありません。

  1. 画像を 1 枚、好きな位置・大きさに置く YMM4 のプレビューでドラッグ・拡大縮小するだけ。生成済みの挿絵でも、手持ちの 画像を仮に置いたものでも構いません。
  2. その画像を選択して「この配置を枠にする」を押す 見えているそのままの矩形が枠になります。以降の生成素材はこの枠に収まります。

見取り図で決める

「素材の配置枠」を開くと、画面の形をした見取り図が出ます。 取り込んだ枠の確認にも使えます。

  • オレンジの枠をドラッグして移動
  • 枠の四隅をドラッグしてサイズ変更
  • プリセットボタン（全画面 / 右上 / 左上 / 上半分）で一発指定

見取り図の縦横比は開いているプロジェクトに合わせて表示されるので、縦動画なら縦長で出ます。 位置関係もそのまま実際の画面と一致します。

枠からはみ出しません。 AI 画像は枠の縦横比で生成するので、枠をちょうど埋めます（余白も切れも出ません）。 実写素材は比率を選べないため枠に内接する形で収まります（少し余白が出ることがありますが、 枠の外へは出ません）。

既定は全画面です。何もしなければ今までと同じ動作です。

枠を使っている間、画像エフェクトはズームのみになります。

スライドは画像を枠より大きく表示しないと動かせず、それは枠の外へはみ出す （＝立ち絵や字幕に被る）ことを意味するためです。自動で切り替わるので操作は不要です。

画像エフェクト

静止画に寄り・引き・スライドのアニメーションを自動で付けます（いわゆる Ken Burns 効果）。 右のドロップダウンで効果の種類を選べます。

動く速さはショットの長さに合わせて自動調整されるので、短いセリフでも長いセリフでも 見た目の速さが揃います。

  • 画像を選んで押す → その画像だけに付く
  • 何も選ばずに押す → 対象レイヤーの全画像に付く

「対象レイヤー」は入れておくことを強くおすすめします。 空欄のままだと、同じ時刻に置いてあるあなた自身の装飾画像まで動いてしまうことがあります。 「レイヤーを自動検出」を押せば素材レイヤーが自動で入ります。

動画アイテムには付きません（すでに動いているため）。

立ち絵の表情を自動設定

各セリフの感情を AI が判定して、立ち絵の表情を自動で切り替えます。 立ち絵のブロックは感情が変わるところで自動的に分割され、位置やサイズはそのまま引き継がれます。

使えるようにするには

YMM4 の立ち絵で表情プリセットを保存してあることが条件です （キャラクター編集 → 立ち絵 → 表情を作って保存）。プラグインはその保存済みプリセットを読み取って使います。

アニメーション立ち絵のみ対応です。1 枚絵のシンプル立ち絵には使えません。

手順

  1. 「表情リストを読み込む」を押す 立ち絵にある表情の名前が一覧で入ります。AI に使ってほしくない表情は削ってください。
  2. 強度しきい値を決める 高くするほど強い感情のときだけ表情が変わります（＝切り替え頻度が下がる）。 弱い行・中立の行はデフォルト表情のままです。
  3. 「感情で表情を自動設定（全体）」を押す 台詞を選んでから「選択した台詞だけ表情を設定」を押せば、その部分だけ変えることもできます （言い終わると元の表情に戻り、他の部分には触れません）。

表情が出ている長さ

表情が変わるのはそのセリフを言っている間だけです。言い終わると通常の顔に戻るので、 相手が喋っている間や無音の区間まで、悲しい顔や怒った顔が貼り付いたままになることはありません。

セリフが切れ目なく続いている場合は、中立の顔を挟まずに次の表情へそのまま切り替わります （わずかな隙間でも顔がちらつかないように調整されています）。

デフォルト表情について

感情が無い（淡々とした説明・相槌など）と判定された行は「デフォルト」になります。 立ち絵に 「デフォルト」という名前の表情プリセットを作っておくと、その顔が使われます。 無い場合は、タイムラインに元々置いてあった顔のままになります。どちらの場合も 前の行の表情が残ってしまうことはありません。

立ち絵の名前とセリフの話者名が違うとき

通常は名前で自動的に対応します。名前が一致していない場合や、触ってほしくない立ち絵がある場合は、 「話者の立ち絵レイヤー」に 話者名とレイヤー を指定してください（「自動検出」で埋まります）。

補足テロップの自動配置

各セリフから強調したいキーワードを AI が抽出して、専用レイヤーに補足テロップを配置します。 毎行は出しません（重要な語だけ）。

見た目は「見本」からそのままコピーされます

好きなテロップを作った .ymmp を 「見本 .ymmp」 に指定してください。 縁取り・背景の箱・登場アニメーションまで、まるごと複製して使われます。

  • スタイル名になるのは、見本のテロップの Remark（備考）。無ければテキストの 1 行目
  • 見本を指定しない場合は、同梱の既定 3 スタイル（強調／情報／補足）が使われます

SE（効果音）を付ける

「テロップに SE を付ける」にチェックを入れると効果音も一緒に配置されます。 鳴らす音は見本 .ymmp から取得します。

やり方：見本 .ymmp で、テロップと同じ時刻に鳴らしたい SE を置いておくだけ。 そのスタイル専用の SE として、音量・フェードの設定ごと引き継がれます。

音量を変えたいときは、見本 .ymmp 側で SE の音量を調整してから実行し直してください。

その他

  • 重要度しきい値：高いほど本当に重要な語だけになります（＝数が減る）。既定 45
  • 表示位置：上下の位置を選べます。字幕と被らない位置は「位置を追加」で自分用に登録できます
  • 再実行すると前回のテロップは作り直しになります（増え続けません）

困ったとき

DLL を置き換えられない / 上書きできない

YMM4 が起動中はファイルがロックされます。YMM4 を完全に終了してから置き換えてください。

ツールメニューに出てこない
  • 置き場所が user\plugin\NarraSync2\ になっているか確認してください（フォルダごと置く）
  • .dll と .deps.json の両方が必要です
  • YMM4 のバージョンが 4.53 か確認してください
表情の詳細を見ると「カスタム」と表示される

問題ありません。絵は正しく設定されています。 YMM4 は表情の名前をプロジェクトに保存せず、パーツの画像そのものを保存する仕組みで、 画面の表示名は「今の組み合わせがどの登録済み表情と一致するか」を照合して出しています。 立ち絵の登録名と台本の話者名がずれていたり、プリセットに含まれないパーツが混ざっていると 照合できず「カスタム」と出ますが、書き出される映像には影響しません。

表情が変わらない / 「表情を設定できませんでした」と出る
  • 立ち絵がシンプル立ち絵（1 枚絵）だと未対応です。アニメーション立ち絵が必要です
  • 立ち絵に表情プリセットが保存されていない可能性があります
  • 表情リストの名前が、立ち絵に登録した表情名と1 文字でも違うと対象外になります（「表情リストを読み込む」で入れるのが確実）
  • 強度しきい値が高すぎて、全部デフォルト判定になっていないか確認してください
画像エフェクトをもう一度押すと、効果が重なりますか？

重なりません。押すたびに前回の効果を打ち消してから付け直すので、 何度押しても結果は同じです。別の効果に切り替えた場合も、前の効果は消えて置き換わります。

画像エフェクトで、動かしたくない画像まで動いた

「対象レイヤー」を指定してから実行してください。空欄のままだと、同じ時刻に置かれた 他のレイヤーの画像も対象になります。「レイヤーを自動検出」で素材レイヤーが自動で入ります。

再生成したらキャラクターの見た目が変わってしまった

「画面再生成」でも角色参照・スタイル参照は反映されます。パネルの角色参照に画像が設定されているか確認してください （空欄のままだと参照なしで作り直されます）。

なお古い版のプラグインには、再生成時だけ参照画像が使われない不具合がありました。 最新版に更新してください。

失敗した / 変になったので元に戻したい

実行前のプロジェクトが プロジェクト名.ymmp.bak として同じフォルダに保存されています。 拡張子の .bak を消せば元のプロジェクトに戻せます。

「まずプロジェクトを保存してください」と出る

一度も保存していない新規プロジェクトでは実行できません。Ctrl+S で保存してから実行してください。

「完了」と出るのに、素材が画面に出てこない

作り直さないでください。素材はできていて、プロジェクトファイルにも書き込まれています。 画面への反映（プロジェクトの読み直し）だけが失敗した状態です。 パネルの「プロジェクトを再読み込み」を押せば出てきます。

ここで作り直すと、画面に残っている「生成前」の状態でファイルが上書きされ、 できていた素材が消えて、生成費用も二重にかかります。 そうならないよう、未反映の間はオレンジ色の警告が出て、実行そのものを止めるようにしています。

読み直しに失敗する原因で多いのは、プロジェクトの保存先が OneDrive などの同期フォルダになっていることです （書き出した直後に同期処理がファイルをつかみ、開けなくなります）。 ウイルス対策ソフトが原因になることもあります。 同期対象外のローカルフォルダに置くと安定します。

自分で YMM4 側から開き直した場合など、すでに反映済みなのに警告が消えないときは、 警告の右にある「解除」を押してください。
