# NarraSync2 YMM4 プラグイン

ゆっくりMovieMaker4 に AI 素材生成を組み込むツールプラグインです。

台本（YMM4 のセリフ）を読み取って、各行に合った挿絵を AI が生成しタイムラインに配置します。
立ち絵の表情や補足テロップの自動配置もできます。
台本を Google スプレッドシートで書いている場合は、シートをそのままタイムラインに変換することもできます。
音声合成・字幕・口パク・エンコードなど YMM4 が既に持つ機能はそのまま使えます。

## 📖 使い方

**→ [導入手順・使い方はこちら](https://fsgni.github.io/narrasync-ymm4-plugin/)**

## ⬇️ ダウンロード

**→ [最新版](https://github.com/fsgni/narrasync-ymm4-plugin/releases/latest)**

zip を展開し、中の `NarraSync2` フォルダごと
`YukkuriMovieMaker_v4\user\plugin\` に置いてください（YMM4 は終了した状態で）。

## できること

- **台本シート（Google スプレッドシート）からタイムラインを作成** —
  セリフ・画像・映像エフェクト・出典表示・カード説明・章題までまとめて配置
- 台本の各セリフに合った挿絵を AI が生成してタイムラインへ配置
- 実写ストック素材（Pexels / Pixabay）の自動挿入
- 画像 → 動画化
- 静止画に寄り／引き／スライドのエフェクト
- セリフの感情から立ち絵の表情を自動設定
- キーワードから補足テロップ＋SE を自動配置

## 動作環境

- ゆっくりMovieMaker4 **v4.53**（内部構造を利用しているため、YMM4 の自動更新はオフ推奨）
- Windows
- NarraSync2 バックエンドへの接続情報（管理者から取得）

## 注意

- 既存のアイテムは書き換えません。生成物は指定レイヤーに追加されるだけです
- 実行前に `プロジェクト名.ymmp.bak` のバックアップが自動で作られます
